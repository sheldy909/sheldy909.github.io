Как я автоматизировал отчётность команды дизайнеров

2026

Я сделал приложение для команды из шести дизайнеров. Оно считает готовые работы в папках и готовит два отчёта: строку для Excel в конце дня и сообщение руководителю в конце недели. С ним дневной отчёт занимает около минуты вместо 5–10.

Прежде чем прийти к этому варианту, я попробовал несколько способов. В одном из них программа сама записывала данные в Excel. На первый взгляд это было удобно, но именно от этой возможности я в итоге отказался.

[Видео-обложка, 10–15 секунд: открыть дневной отчёт в приложении → скопировать строку → вставить её в Excel. Подпись: «Как данные из папок попадают в дневной отчёт».]

Что происходит с картинками после того, как они готовы

В течение дня дизайнер сохраняет готовые картинки в личную папку с отчётностью. У каждого дня своя папка. Внутри работы делятся по типу — разработка, размножение и правки — и по сложности: S, M и L. Всего получается девять подпапок. От того, в какой из них лежит картинка, зависит, сколько баллов за неё начисляется.

В конце дня нужно внести количество работ по каждой категории в общую таблицу. Excel сам считает баллы по формуле. Ручная часть начинается раньше: открыть папки за сегодня, пересчитать картинки в каждой и перенести числа в нужные столбцы. Чем больше файлов, тем дольше подсчёт.

Я решил использовать саму структуру папок: дата, тип и сложность уже известны, остаётся посчитать содержимое. Первой идеей был обычный HTML-файл. Но страница в браузере не может сама открыть нужные папки на компьютере и прочитать их содержимое, поэтому этот вариант не подошёл.

Почему я перестал записывать данные в Excel автоматически

Следующую версию я сделал в виде батника — файла с командами для Windows. Первый вариант умел при запуске сам вносить результаты в Excel. Это экономило один шаг, но автоматическая запись могла повредить общий файл на сетевом диске. Даже просто открыть батник, чтобы посмотреть свои баллы, было нельзя: запуск уже означал запись в таблицу.

В одной из ранних версий результаты за сегодня и за неделю просто выводились на экран сразу после запуска. Для подсчёта этого хватало, но интерфейса почти не было: оба отчёта появлялись сразу, даже если нужен был только один.

Затем я добавил меню. В нём можно было выбрать дневной отчёт, личный или общий недельный отчёт, а также настроить путь к папке. Для переноса данных появилась команда копирования. Теперь дизайнер сам решал, когда вставить значения в Excel: можно было сначала посмотреть результаты и закрыть отчёт, ничего не меняя в таблице. Этот вариант стал прототипом нынешнего приложения.

Один файл на шестерых

У батника оставалось неудобство, которое меню не решало: на общий сетевой диск файлы .bat могли загружать только администраторы. Поэтому приходилось готовить личный файл для каждого дизайнера и передавать его отдельно. У каждого лежала своя копия на рабочем столе.

Нынешнюю версию я сделал в формате HTA — это приложение для Windows с интерфейсом на HTML, которое может читать файлы и папки. На общем сетевом диске этот формат разрешён, поэтому там можно держать один файл на всю команду. При этом путь к личной папке сохраняется у каждого дизайнера отдельно. Файл общий, а данные у каждого свои.

Для дневного отчёта приложение находит нужные папки за сегодня, считает картинки и собирает значения в порядке столбцов Excel. Дизайнеру остаётся скопировать строку и вставить её в таблицу. Количество файлов больше не добавляет ручной работы: открывать папки по очереди и считать картинки самому не нужно.

Недельная сводка сразу в виде сообщения

На дневной таблице отчётность не заканчивалась. В конце недели нужно было отправить руководителю сообщение: сколько работ сделано по каждой категории и сколько баллов набралось за все дни. Для этого дизайнер снова открывал общий Excel-файл, отбирал свои строки и вручную переносил итоги в чат.

Для этого в приложении есть отдельный режим. Он собирает данные из папок за все дни недели и формирует готовый текст с количеством работ по категориям и общей суммой баллов. Дизайнер копирует его в чат и отправляет руководителю.

Приложением пользуются все шесть дизайнеров. Сохранять работы по-прежнему можно в привычные папки, дневные данные — вносить в общую таблицу, а недельные итоги — отправлять в чат. Из этой цепочки я убрал ручной пересчёт вечером и повторный сбор тех же цифр в конце недели.
