Everything: как я ищу десятки файлов за секунды

В моей работе постоянно возникает задача искать файлы по кодам товаров. У компании большая база, и у каждого товара десятки изображений — чаще всего это тяжелые .psd. Стандартный поиск Windows в таком сценарии начинает откровенно тормозить. Чем больше файлов на диске, тем дольше ждёшь результат.

Everything решает это за счёт индексации — он заранее «знает» все файлы в системе и потом ищет их практически мгновенно. Разница ощущается сразу, особенно если работаешь с большими объёмами.

Как я его использую

Мой основной сценарий: ввожу код товара или часть имени файла и сразу вижу всё, что совпадает.

Можно искать:

  • по части имени

  • по расширению (.psd, .jpg)

  • комбинировать запросы

В большинстве случаев этого уже достаточно, чтобы быстро найти нужные файлы.

Поиск сразу нескольких файлов

В Everything есть полезная штука — поиск нескольких значений одновременно через | (или). Выглядит это так:

12345 | 67890 | 54321

В ответ получаешь совпадения сразу по всем трём кодам. Удобно, когда нужно найти несколько файлов за один раз.

Проблема возникает, когда список не из трёх позиций, а, например, из 20-50. Вручную расставлять | между каждым значением — это просто лишняя рутина.

Как я это автоматизировал

Я написал простой .bat-скрипт под эту задачу.

Логика у него незамысловатая:

  1. Берёт текст из буфера обмена

  2. Удаляет всё лишнее (буквы, знаки, мусор)

  3. Оставляет только цифры

  4. Ставит между ними |

  5. Копирует результат обратно в буфер

Рабочий процесс теперь выглядит так: скопировал список кодов откуда угодно — из таблицы, письма, задачи — запустил скрипт, вставил в Everything. Готово.

Сам скрипт

@echo off
chcp 65001 >nul
setlocal

powershell -nologo -command ^
    "$raw = Get-Clipboard -Raw;" ^
    "$clean = $raw -replace '[^\d]+', ' | ';" ^
    "$clean = $clean -replace '(\s*\|\s*)+', ' | ';" ^
    "$clean = $clean.Trim(' |');" ^
    "Set-Clipboard -Value $clean"

Когда это особенно полезно

Скрипт изначально написан под коды товаров, но по факту работает в любой ситуации, где есть список значений, по которому нужно что-то найти. Артикулы, номера заказов, идентификаторы файлов — механика одна и та же.

Что в итоге

Everything закрывает базовую проблему поиска файлов, делая его таким, каким он и должен быть по умолчанию. А такие небольшие доработки, как этот скрипт, позволяют подогнать инструмент под свой рабочий процесс и убрать лишние действия.
